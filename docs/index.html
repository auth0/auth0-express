Auth0 Express SDKs

API reference for the packages in auth0/auth0-express.

  • @auth0/auth0-express
    Authentication for Express web apps: login, logout, callback and back-channel logout routes, sessions, and access tokens to call APIs on behalf of the user.
  • @auth0/auth0-express-api
    Protect Express API routes with Auth0 access tokens: require a valid Bearer token, check scopes and claims, and exchange the caller's token to call other APIs.
